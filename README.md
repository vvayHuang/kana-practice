# かな練習帳

日文五十音練習網頁：平假名、片假名對照表，以及假名、單字、句子和情境題的小測驗。

線上版：https://vvayhuang.github.io/kana-practice/

## 功能

- **三個分頁：假名、單字、句子**：照學習的順序排。每一頁上面先看熟悉度，最下面一直有一個「練習」按鈕，按下去選範圍、題型和題數就能開始測驗。
- **假名分頁**：五十音表，有清音、濁音・半濁音、拗音。點假名會發音，並顯示平假名／片假名對照和念法提醒。還沒有練習紀錄時，最上面會有一張「從這裡開始」的引導；熟練了 10 個以上的假名、還沒練過單字時，會提醒可以去練單字。
- **假名測驗**：看假名選拼音，或看拼音選假名。可以選平假名、片假名或混合，也可以只練某幾行。
- **單字分頁**：單字本，列出用已選範圍的假名就能寫出來的單字（平假名、片假名分開列），標出每個單字的熟練度，可以只看常答錯、練習中或還沒練的。點一下單字會發音，並展開字典解釋。熟練了 10 個以上的單字、還沒練過句子時，會提醒可以去練句子。
- **單字測驗**：練習念法（單字→拼音）和意思（單字→意思、意思→單字）。只會出現用已選範圍的假名就能寫出來的單字。答完後題目下方會出現像字典一樣的解釋：意思、念法、詞性、漢字或外來語來源、使用情境和例句（可以聽發音），看完再按「下一題」。
- **句子分頁**：最上面是 8 個情境題的卡片（打招呼、自我介紹、餐廳點餐、便利商店、車站問路、購物、飯店、身體不舒服），卡片上用記號標出每一題的熟練度；點進去可以先看、先聽每一題的說法和解說。下面列出單字本裡那些單字的例句（每個單字附一句，只用假名寫），點一下會念整句，並顯示拼音和出自哪個單字。最下面有「練習情境題」和「練習例句」兩個按鈕。
- **情境題**：共 56 題。有兩種：遇到某個場合要怎麼說（例如在餐廳想結帳），和對方這樣說時要怎麼回（例如店員問「ふくろは いりますか」）。對方說的話會自動念出來，可以重聽。錯的選項大多是「意思對但場合不對」的說法，答完每個選項都會寫出意思，題目下面有「為什麼」的解說。可以只練一個情境，也可以選好幾個一起練。
- **句子測驗**：三種題型，可以只練一種或混合：
  - 排句子：看中文，把打散的詞依順序排好。裡面混了兩個多的詞，不能只靠刪去法。
  - 選意思：看日文句子，選中文意思。
  - 聽句子：只聽聲音，選中文意思。裝置沒有日文語音時不會出這一種。
  可以打開「拼音」提示；答完會顯示整句、拼音和出自哪個單字。
- **練習範圍**：要練哪幾行假名是三個分頁共用的設定，在任一邊的練習設定裡改都可以。單字只出用這些假名寫得出來的，例句只出這些單字的例句。情境題不看假名範圍，改成選要練哪些情境。
- **熟練度**：表格上方有說明，會用形狀標出已熟練（墨點）、練習中（墨圈）、常答錯（朱紅色的叉，至少錯兩次才算）。常答錯的假名、單字或句子，在測驗時一定會優先出現（最多佔一半題數），答對幾次、正確率回升後就不再算常錯。
- **自動調整難度**：測驗會記錄答對、答錯次數和作答時間。常錯或還沒練過的假名比較常出現，已熟練的比較少；答對但平均超過 3 秒的還是算「練習中」；選項會優先放容易混淆的假名（例如 ぬ／め、シ／ツ）。
- **雲端同步**：在 claude.ai 上打開（Claude 版）並登入時，答題紀錄會同步到你的 Claude 帳號，手機、電腦看到的是同一份。點右上的雲按鈕，可以看到每份紀錄是哪台裝置（例如「iPhone · Safari」）、答了幾題、最後什麼時候練習。其他地方打開（例如 GitHub Pages）時，紀錄只存在瀏覽器裡。

發音用的是瀏覽器內建的日文語音，不需要網路或 API key。如果裝置沒有日文語音，會跳出提示。

## 外觀

畫面是一張習字紙：整頁白紙，字用墨色寫，顏色只留給答題狀態：答錯和常答錯是朱紅色，答對是綠色。頁首是一條墨色的帶子，作答時會收起來。假名都寫在有十字虛線的習字格裡。設計規則記在 `DESIGN.md`，產品背景記在 `PRODUCT.md`。

## 執行

```bash
npm install
npm run dev
```

打開 http://localhost:5173 就能使用。輸出正式版用 `npm run build`，檔案會在 `dist/`。

## 新增或修改情境題

情境題寫在 `src/scenes.js` 最上面的文字裡，一行一項，開頭的符號表示這一行是什麼：

```
@konbini 便利商店 | ふくろは いりますか。

? 結帳的時候，店員這樣問你。你不需要袋子，要怎麼回答？
> ふくろは いりますか。| 需要袋子嗎？
= いいえ、だいじょうぶです。| 不用了，沒關係
- はい、おねがいします。| 好，麻煩你（會幫你裝袋）
- いただきます。| 我開動了
- どういたしまして。| 不客氣
! 「だいじょうぶです」在這裡是客氣地說「不用了」。
```

- `@`：一個新的情境：代號（英文小寫，用在網址）、名稱，`|` 後面是卡片上的例句
- `?`：題目，寫場合和要問的事
- `>`：對方說的話（日文｜中文），接話題才需要；中文要答完才會顯示
- `=`：正確的說法（日文｜中文意思）
- `-`：錯的說法，要剛好三個
- `!`：答完顯示的解說

日文只用假名，詞和詞之間空一格。選項只寫中文、日文留空（例如 `= | 直走，然後右轉`）時，就是「看懂對方的話，選出意思」的題目。練習紀錄是用「情境代號＋正確答案」記的，改了正確答案的日文，那一題的紀錄會重新算。

## 發佈到 GitHub Pages

推送到 `main` 後，`.github/workflows/deploy-pages.yml` 會自動打包（`npm run build:pages`）並更新線上版。

第一次使用前，要到 repo 的 **Settings → Pages**，把 **Source** 選成 **GitHub Actions**。

## 檔案

- `src/kana.js`：假名資料（片假名由平假名自動換算）
- `src/words.js`：單字資料（拼音由假名自動換算）
- `src/dict.js`：單字的字典解釋（詞性、漢字或來源、使用情境、例句）
- `src/main.js`：頁首分頁和網址（`#kana`、`#words`、`#sentences`，各自加 `/quiz` 是練習；舊的 `#chart`、`#quiz` 會自動轉過去）
- `src/chart.js`：假名分頁的五十音表
- `src/book.js`：單字本和句子列表共用的清單頁（熟練度統計、篩選、點開看解釋、底部的練習按鈕）
- `src/wordbook.js`：單字分頁的單字本
- `src/sentencebook.js`：句子分頁的例句列表
- `src/sentences.js`：句子資料（從 `dict.js` 的例句來）、拼音、排句子的詞塊和干擾選項
- `src/scenes.js`：情境題的內容（新增或修改情境題就改這個檔案，寫法見下面）
- `src/scenebook.js`：句子分頁上的情境卡片，和每個情境的題目列表
- `src/quiz.js`：測驗（設定、作答、結果），假名、單字、句子共用
- `src/range.js`：練習範圍（選了哪幾行、能寫出哪些單字）
- `src/entry.js`：單字的字典解釋畫面，單字測驗和單字本共用
- `src/store.js`：練習紀錄與設定
- `src/sync.js`：雲端同步（只在 claude.ai 上有作用）
- `src/syncPanel.js`：右上的雲按鈕和裝置清單
- `src/speech.js`：發音

## 發佈 Claude 版

```bash
npm run build:artifact
```

會輸出單一 HTML 檔 `dist-artifact/kana-practice.html`。發佈時要開啟 `db` 和 `user` 兩個功能，雲端同步才會運作。雲端資料存在 `data/users/<使用者>/<裝置>`，只有本人看得到。每台裝置各存一份 `{ stats, label, lastAt }`：答題次數、裝置名稱和最後答題時間（舊版存的只有 `stats`），畫面上顯示的是全部加起來的結果。

「裝置」其實是瀏覽器裡存的一個編號：換瀏覽器、用無痕視窗，或網站資料被清掉後，會變成新的一份，所以份數常比實際的裝置多。雲按鈕因此不顯示數字，只在清單上列出每一份。
