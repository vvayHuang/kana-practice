# かな練習帳

日文五十音練習網頁：平假名、片假名對照表和小測驗。

線上版：https://vvayhuang.github.io/kana-practice/

## 功能

- **五十音表**：清音、濁音・半濁音、拗音。點假名會發音，並顯示平假名／片假名對照和念法提醒。
- **測驗**：看假名選拼音，或看拼音選假名。可以選平假名、片假名或混合，也可以只練某幾行。
- **單字測驗**：測驗的「內容」可以切到單字，練習念法（單字→拼音）和意思（單字→意思、意思→單字）。只會出現用已選範圍的假名就能寫出來的單字。答完後題目下方會出現像字典一樣的解釋：意思、念法、詞性、漢字或外來語來源、使用情境和例句（可以聽發音），看完再按「下一題」。
- **熟練度**：表格上方有顏色說明，會標出已熟練、練習中、常答錯（至少錯兩次才算）。常答錯的假名或單字，在測驗時一定會優先出現（最多佔一半題數），答對幾次、正確率回升後就不再算常錯。
- **自動調整難度**：測驗會記錄答對、答錯次數和作答時間。常錯或還沒練過的假名比較常出現，已熟練的比較少；答對但平均超過 3 秒的還是算「練習中」；選項會優先放容易混淆的假名（例如 ぬ／め、シ／ツ）。
- **雲端同步**：在 claude.ai 上打開（Claude 版）並登入時，答題紀錄會同步到你的 Claude 帳號，手機、電腦看到的是同一份。其他地方打開（例如 GitHub Pages）時，紀錄只存在瀏覽器裡。

發音用的是瀏覽器內建的日文語音，不需要網路或 API key。如果裝置沒有日文語音，會跳出提示。

## 執行

```bash
npm install
npm run dev
```

打開 http://localhost:5173 就能使用。輸出正式版用 `npm run build`，檔案會在 `dist/`。

## 發佈到 GitHub Pages

推送到 `main` 後，`.github/workflows/deploy-pages.yml` 會自動打包（`npm run build:pages`）並更新線上版。

第一次使用前，要到 repo 的 **Settings → Pages**，把 **Source** 選成 **GitHub Actions**。

## 檔案

- `src/kana.js`：假名資料（片假名由平假名自動換算）
- `src/words.js`：單字資料（拼音由假名自動換算）
- `src/dict.js`：單字的字典解釋（詞性、漢字或來源、使用情境、例句）
- `src/chart.js`：五十音表
- `src/quiz.js`：測驗
- `src/store.js`：練習紀錄與設定
- `src/sync.js`：雲端同步（只在 claude.ai 上有作用）
- `src/speech.js`：發音

## 發佈 Claude 版

```bash
npm run build:artifact
```

會輸出單一 HTML 檔 `dist-artifact/kana-practice.html`。發佈時要開啟 `db` 和 `user` 兩個功能，雲端同步才會運作。雲端資料存在 `data/users/<使用者>/<裝置>`，只有本人看得到。每台裝置各存一份自己的次數，畫面上顯示的是全部加起來的結果。
